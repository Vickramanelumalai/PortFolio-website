# Portfolio site

Two pages: `index.html` (IT career, minimal) and `creator.html` (content creator, funky).

## Change text, links or images
Open `content.js` and edit the values. Nothing else needs touching.
Put images in `assets/` and reference them, e.g. `"assets/profile.jpg"`. An empty `""` hides the image.

## Preview locally
Double-click `index.html`.

## Publish with GitHub Pages
```
git add .
git commit -m "Add portfolio site"
git push
```
Then on GitHub: Settings > Pages > Deploy from a branch > `main` / root.
